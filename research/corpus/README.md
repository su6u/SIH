# Corpus notes

This directory contains an automated discovery corpus, not a 2,879-paper reading claim.

The CSV/JSONL files were generated from OpenAlex on 2 September 2026 using the query and screening method documented in [`../01-research-method.md`](../01-research-method.md). The most useful records were then checked manually against paper pages, repositories and official documentation before entering the curated bibliography.

`screening_shortlist.csv` is a 250-item queue that favors recent work with directly relevant titles. It is a prioritization aid, not a quality score.
